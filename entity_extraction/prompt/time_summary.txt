🔧 Task Description:
You are given a clinical summary from a patient’s hospital stay.
Your task is to extract only those clinical events that serve as temporal anchors, which can be used to infer the dates of other events.

📌 Instructions:
1. If there are events described with relative time expressions (e.g., “a few days later,” “on the nth day,” “the next day”),
extract only the anchor event(s) that allow these events to be assigned an exact date.
2. Criteria for events to be extracted:
- The event must serve as a practical anchor for determining the timing of another event.
- Include Admission and Discharge if they are used to infer other event dates.
3. Output format
yyyy-mm-dd - Event description  
yyyy-mm-dd - Event description
4. The following should be excluded from the output:
- Events described only with relative expressions such as “3 days later” or “the next day”
- Events that have a clear date but are not used to infer the date of any other events

Example 1
🟩 Clinical Note:
The patient was admitted on 2171-06-01 with confusion and fever. Blood cultures were taken on the admission day.
On 2171-06-05, MSSA was confirmed and vancomycin was started.
The fever resolved two days after starting the antibiotics.
The patient was discharged on 2171-06-10. Acetaminophen was prescribed at discharge.

🟦 Output:
2171-06-01 - Admission  
2171-06-05 - vancomycin was started 
2171-06-10 - Discharge

📝 Explanation:
1. 2171-06-01 - Admission:
Events like the blood culture are described as occurring "on admission day", not with a specific date.
The admission date is needed to calculate that date → included as anchor.

2. 2171-06-05 - vancomycin was started:
Fever resolution is described as “2 days after antibiotics began”, making this an anchor → included.

3. 2171-06-10 - Discharge:
“At discharge” acetaminophen was prescribed → the discharge date anchors that → included.

4. Blood culture:
Even though linked to admission day, it's not itself used as an anchor → excluded.

5. MSSA confirmation:
The event has a clear date but is not used to calculate the timing of other events → excluded.

6. Acetaminophen prescription:
Occurs “at discharge”, which relies on the discharge date; not itself an anchor → excluded.
